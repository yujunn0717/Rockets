# Rockets Lineup Manager v1.0.2.8


GitHub 저장소 루트에 모든 파일을 그대로 업로드하는 배포 구조입니다.

수정 사항:
- 야구장 이미지 및 아이콘 경로를 저장소 루트 기준으로 변경
- iPhone 14 Pro 폭에서 위치 보정값 비례 축소
- 모바일 포지션 박스와 벤치 패널 크기 축소
- 서비스워커 캐시 v1.0.1로 갱신


## v1.0.2
- 포지션 박스의 선수 이름과 포지션 사이 불필요한 줄 간격 제거
- 모바일 박스 높이와 좌표는 유지
- 서비스워커 캐시 버전 갱신


## v1.0.2.1
- 벤치 표는 등번호와 이름만 표시합니다.
- 홈 화면 설치 시 세로 방향을 요청하며, 가로 화면에서는 세로 회전 안내를 표시합니다.


## v1.0.2.2
- 아이폰 등 단말 가로 화면에서는 필드 이미지를 숨기고 선발·벤치 라인업 표만 표시합니다.
- iPad 가로 화면에서는 기존처럼 필드 이미지를 유지합니다.
- 화면 방향 고정 요청을 제거해 단말 가로 모드를 사용할 수 있습니다.


## v1.0.2.3
- 상단 저장 버튼을 라인업 저장으로 변경
- 공유 버튼을 저장으로 변경
- 포지션 / 라인업 / 포지션+라인업 PNG 저장 선택 추가


## v1.0.2.5
- JS/CSS 파일명을 변경해 이전 서비스워커 캐시를 우회합니다.
- 구버전 언어 저장값을 한국어/영어/일본어 코드로 자동 변환합니다.
- 이미지 저장 버튼은 항상 3개 선택창을 먼저 표시합니다.


## v1.0.2.5
- 포지션 탭 기본 제목을 `Title`로 변경
- 요청한 15명 선수 명단과 주 포지션으로 기본 데이터 교체
- 중복 수비 없는 10명 선발 및 5명 벤치 기본 라인업 구성


## v1.0.2.6
- 선발·벤치 영역 중앙에 Rockets 로고 워터마크 적용
- 포지션 탭 하단 표, 라인업 탭 선발/벤치 카드, 저장 이미지에 동일 스타일 적용


## v1.0.2.7
- 모바일에서 JS 실행을 중단시키던 워터마크 삽입 문법 오류 수정
- 선수 박스, 선발/벤치 표 렌더링 복구
- 워터마크 기능 유지

- 라인업 탭의 선수 선택 이름에는 등번호를 제외하고 이름만 표시합니다.
- 앱 이름을 Rockets Lineup Manager로 변경했습니다.


## v1.0.2.9
- 선발/벤치 카드 워터마크 복구
- 설정에서 팀명, 기본 출전 선수 수, 언어 항목 제거
- 지명타자 및 벤치 표시 라디오 버튼 가로 정렬
- 백업/복원/초기화 버튼 크기와 글꼴 통일


## v1.0.2.10
- 포지션 탭의 선발 영역과 벤치 영역에 각각 독립적인 중앙 워터마크를 배치했습니다.
- 기존처럼 선발·벤치 전체에 걸쳐 하나만 보이던 워터마크를 제거했습니다.


## v1.0.2.11
- 포지션 탭 하단 선발표의 포지션 칸을 짧게 누르면 포지션 선택 목록이 열립니다.
- 포지션 칸을 0.42초 이상 길게 누른 뒤 드래그하면 기존처럼 다른 선수와 포지션을 교환할 수 있습니다.


## v1.0.2.12
- 저장 이미지의 선발표에서 이름·포지션 영역을 5:5로 배치했습니다.
- 저장 이미지의 선발·벤치 영역 각각 중앙에 워터마크를 표시합니다.


## v1.0.2.13
- 홈 화면 아이콘을 Rockets 워터마크 로고로 변경
- iPhone/iPad용 Apple Touch Icon 추가
- Android PWA용 192px/512px 아이콘 및 maskable 아이콘 적용
- 브라우저 파비콘 추가


## v1.0.2.16
- iOS Safari에서 포지션 칸 짧은 탭이 반응하지 않던 문제 수정
- 짧게 탭하면 포지션 선택창, 0.42초 롱프레스 후 이동하면 드래그 교환


## v1.0.2.16
- v1.0.2.14 기반 수정
- 포지션 칸은 iOS/Android 네이티브 드롭다운으로 변경
- 별도 ≡ 핸들을 0.42초 롱프레스한 경우에만 포지션 드래그 교환
- 드래그 중 페이지 스크롤 잠금
- 선발·벤치 하단 명단 렌더링 유지

## v1.0.2.16
- v1.0.2.14의 정상 렌더링을 기준으로 포지션 선택 UI를 다시 구현했습니다.
- 포지션 글자 영역은 iOS/Android 네이티브 드롭다운으로 동작합니다.
- 우측 ≡ 핸들을 0.42초간 길게 누르면 포지션 교환 드래그가 시작됩니다.
- 드래그 중 페이지 스크롤을 잠급니다.
- 벤치 선수를 선발 행에 놓으면 해당 타순의 선수와 정확히 교체됩니다.
- 교체된 선발 선수는 선택한 벤치 선수의 기존 벤치 순번으로 이동합니다.


## v1.0.2.17
- 중복 포지션 경고를 `중복 포지션 배치 : 포지션명` 형식으로 표시
- 중복 선수 경고를 `중복 선수 출전 : 이름` 형식으로 표시
- 경고 문구를 진한 빨간색으로 강조
