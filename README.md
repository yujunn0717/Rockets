- 서비스워커 캐시 v1.0.1로 갱신

## v1.1
- 설정 탭에 `출전 관리` 아코디언 목록을 추가했습니다.
- 저장 경기 제목에 연도(예: 2026)와 `전반기` 또는 `후반기`가 모두 포함된 경기만 출전 집계 대상으로 표시합니다.
- 출전 관리의 선수 체크는 기본적으로 전체 선택이며, 실제 미출장 선수만 체크 해제 후 `출전 저장`합니다.
- `미확정` 경기는 출장 수에 포함되지 않고, 출전 저장을 완료한 경기만 시즌/전후반기 출장 수에 집계됩니다.
- 연습경기 및 전/후반기 구분이 없는 제목은 출장 집계에서 제외합니다.
- 라인업/포지션+라인업 PNG의 선발·벤치 표에 현재 제목의 전반기 또는 후반기 출장 경기 수를 자동 표시합니다.
- 시즌 전체 출장 수와 전반기/후반기 출장 수를 내부적으로 각각 계산할 수 있는 구조를 추가했습니다.
- 포지션 탭 하단 선발표의 `#` 헤더를 `타순`으로 변경했습니다.
- 앱 버전을 1.1로 갱신했습니다.


## v1.1.1
- 출전 관리 선수 목록을 팀 전체 명단이 아닌 해당 경기의 저장된 선발 + 벤치 로스터만 불러오도록 변경했습니다.
- 저장 경기 로스터에 포함되지 않은 선수는 출전 관리 체크 목록에 표시되지 않습니다.
- 경기 로스터 선수는 기본 전체 체크되며, 실제 미출전 선수만 체크 해제하는 기존 흐름은 유지합니다.
- 앱 버전을 1.1.1로 갱신했습니다.

## v1.1.2
- 설정 탭 진입 시 출전 관리 아코디언이 항상 모두 접힌 목록 상태로 시작합니다.
- 데이터 영역에 `공유` 버튼을 추가했습니다.
- 데이터 버튼 순서를 `백업 / 복원 / 공유 / 초기화`로 정리했습니다.
- `공유`는 선수 명단, 현재 라인업, 저장 경기, 출전 관리 정보 및 설정을 포함한 전체 JSON 데이터를 공유합니다.
- Web Share API를 지원하지 않는 환경에서는 동일한 JSON 백업 파일을 저장하는 방식으로 대체합니다.
- 기존 v1.1.1 및 이전 형식의 JSON 복원 흐름은 유지합니다.

## v1.2
